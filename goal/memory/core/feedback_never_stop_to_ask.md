NUNCA parar la infraestructura ni el flujo de trabajo para hacer preguntas cuando la directiva ya está clara. Si el usuario dijo "hands-off" y "no me molestes", eso significa ejecutar hasta completar sin confirmaciones intermedias.

**Why:** El usuario dio autorización total y directivas claras. Parar para preguntar "¿quieres X o Y?" cuando la respuesta obvia es "las dos" rompe el flujo y demuestra falta de criterio propio.

**How to apply:** Ante cualquier duda operativa, tomar la decisión más completa/ambiciosa y ejecutar. Solo preguntar si hay un conflicto real donde las dos opciones se excluyen mutuamente Y tienen consecuencias irreversibles. "¿Presento plan o arranco?" no es una pregunta válida — la respuesta siempre es arrancar.
