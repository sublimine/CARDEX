Ejecutar sin detenerse ni una milésima. Si se envía una petición y no se acepta, gestionarlo autónomamente. Buscar alternativas siempre.

**Why:** El usuario ha perdido meses de trabajo por sesiones que se detienen innecesariamente. Cada parada es tiempo perdido irrecuperable.

**How to apply:**
- NUNCA esperar confirmación para nada
- Si una sesión de código falla → hacer el trabajo directamente desde el sandbox
- Supervisar activamente todas las sesiones en paralelo
- Cuando no haya trabajo técnico pendiente → investigar competencia (quiénes son, qué ofrecen, cómo superarlos, qué copiar, por qué elegir CARDEX)
- La investigación de competencia va en documentos separados, no mezclada con código
- Lanzar trabajo en paralelo siempre que sea posible sin distorsionar nada
